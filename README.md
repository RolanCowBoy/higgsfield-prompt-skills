# Higgsfield Prompt Skills

Пять скиллов для подготовки и проверки промптов изображений и видео в Higgsfield.

| Скилл | Задача |
| --- | --- |
| [hf-prompt-review](hf-prompt-review/SKILL.md) | Проверка и исправление противоречий в промптах |
| [hf-character-design](hf-character-design/SKILL.md) | Создание персонажа: силуэт, пропорции, внешность, характер и реквизит |
| [hf-reference-sheet](hf-reference-sheet/SKILL.md) | Ракурсы, эмоции и позы с сохранением утверждённого дизайна |
| [hf-image-edit](hf-image-edit/SKILL.md) | Точечные правки и работа с несколькими референсами |
| [hf-video-acting](hf-video-acting/SKILL.md) | Читаемое актёрское действие в одном кадре |

## Состав

Каждая папка содержит `SKILL.md`, метаданные `agents/openai.yaml`, общее руководство `references/prompt-core.md` и примеры по своей задаче. Копия общего руководства включена в каждый скилл, чтобы он мог работать самостоятельно.

## Использование

Выберите скилл по задаче и передайте ассистенту его `SKILL.md` вместе с референсами, желаемым результатом и ограничениями. Ассистент должен прочитать связанные инструкции из `references/`.

Примеры запросов:
- «Проверь этот промпт: один кадр, 4 секунды, камера неподвижна».
- «Создай героя по описанию; один вариант на белом фоне».
- «Сделай лист утверждённого персонажа: фас, профиль, спина и три эмоции».
- «Перенеси лицо и волосы из референса B в сцену A, сохрани её стилистику».
- «Переведи намерение героя в короткое видимое действие».

Обсуждение — на языке пользователя, готовый промпт — на английском, если не указано иначе. Написание промпта не запускает генерацию.

## Статус

Структура всех пяти скиллов проверена. Выполнены практические проверки написания промптов; по ним уточнены инструкции. Проверка реальными генерациями в Higgsfield ещё не проводилась.

Хранение на GitHub само по себе не устанавливает скиллы в меню ChatGPT/Codex. Это исходники для дальнейшего использования и развития.

Методика разработана на основе разбора корпуса PASSPORT RUSH. Примеры служат иллюстрациями метода и не являются доказательством качества генерации. Исходный корпус и проектные изображения в этот репозиторий не включены.
